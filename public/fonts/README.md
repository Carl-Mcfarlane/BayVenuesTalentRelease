# Brand fonts

Bay Venues' primary typeface is Museo Sans (weights 300, 500, 700, 900); the approved fallback is Calibri.
Museo Sans is a licensed font and is not included. To use it, add web-font files you are licensed to serve here:

- MuseoSans-300.woff2
- MuseoSans-500.woff2
- MuseoSans-700.woff2
- MuseoSans-900.woff2

Calibri is not bundled either (it isn't licensed for web embedding); devices without it fall back to their system font.

NotoSans-Regular.ttf is used only to print the filled-in answers onto the PDF.
