# Brand fonts

Bay Venues' primary typeface is Museo Sans (weights 300, 500, 700, 900); the approved fallback is Calibri.
Museo Sans is a licensed font. The files below are in this repo and are served publicly with the site, so keep the repository private and make sure the licence allows website use. To replace or update them, use these file names:

- MuseoSans-300.otf
- MuseoSans-500.otf
- MuseoSans-700.otf
- MuseoSans-900.otf

Calibri is not bundled either (it isn't licensed for web embedding); devices without it fall back to their system font.

NotoSans-Regular.ttf is used only to print the filled-in answers onto the PDF.
